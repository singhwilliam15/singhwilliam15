### Featured Projects

| Project | What it does | Key tech |

| [**Risk Analysis Tool**](https://github.com/singhwilliam15/Risk-Analysis-Tool) · [▶ live demo](https://risk-analysis-tool.streamlit.app/) | Market, liquidity, credit, concentration and event risk for NSE/BSE/US stocks and portfolios, run through one linked stress engine (pledge fire-sales and circuit locks as a price fixed point, exact Shapley split).
